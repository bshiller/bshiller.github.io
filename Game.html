One-time setup

Connect a free Firebase database

Live multiplayer needs one shared place for bids to land. Firebase's free tier handles a class of any realistic size. This takes about five minutes:

  1. Go to console.firebase.google.com, sign in with any Google account, and click Create a project (name it anything; Analytics can be off).
  2. In the left menu choose Build → Realtime Database → Create database. Pick the default location and start in test mode.
  3. Click the gear icon → Project settings. Under "Your apps," click the </> (web) icon, register an app (no hosting needed), and copy the firebaseConfig object it shows you.
  4. Open this HTML file in a text editor, find FIREBASE_CONFIG near the top of the script, and paste your values over the placeholders. Make sure databaseURL is included (copy it from the Realtime Database page if it isn't in the snippet).
  5. Re-upload the file to your website. Done — this screen disappears.

Test-mode rules expire after 30 days; the README that came with this file has two lines of permanent rules to paste in before the semester starts.
