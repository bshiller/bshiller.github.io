This page needs a Firebase Realtime Database so the class can play from their phones and you can see everyone's results on the projector.

  1. Open this file in a text editor and find FIREBASE_CONFIG near the top of the script.
  2. Paste your project's config from the Firebase console (Project settings → Your apps). Keep the name FIREBASE_CONFIG, and make sure it includes databaseURL.
  3. Upload the file and reload this page.

The same project you use for the other class games works. Sessions are stored under games/dec-CODE.

Decouple?

The United States and China are deeply economically intertwined. For the next 15 simulated years, you run U.S. economic policy toward China. Not "decouple or don't" — where, how much, and why.

This is a model, not a forecast. The numbers illustrate economic mechanisms; economists disagree about their magnitudes.

Run a session

Students open this same page, enter the 4-letter code and their name. You control when each round opens; students see their own results the moment they submit. At the end, the projector shows the whole class.
